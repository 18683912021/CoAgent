## 需求描述
在已有音频采集 PoC（MediaProjection + AudioRecord）基础上，增加一个**可视化测试面板**，让 boss 打包安装后能直观看到采集状态，并把音频存下来给后续 BE 测试用。

## 功能点

### 1. 采集状态指示灯
- 🟢 绿色：正在采集
- 🔴 红色：已停止
- 🟡 黄色：等待权限 / 权限被拒
- 状态文字辅助说明（如「采集中」「已停止」「等待授权」）

### 2. 实时计时器
- 显示格式：`00:03:27`（时:分:秒）
- 开始采集时启动，暂停/停止时冻结

### 3. 音量指示
- 简易音频电平条（当前帧 PCM 幅度的可视化）
- 有数据跳动 = 确认音频在流入
- 不需要精确 dB 值，能肉眼看出「有声音」即可

### 4. 音频文件保存
- 采集到的 PCM 流写入本地文件（如 `interview_20260715_143022.pcm` 或 `.wav`）
- 文件名含时间戳，方便区分
- 保存路径可配置，默认放 App 内部存储（`/data/.../files/`）
- 可选：提供一个「导出」按钮，把文件复制到 Download 目录方便 adb pull

### 5. 音频格式
FE/BE 自行对齐，建议：**16kHz / 16bit / 单声道 PCM**（与腾讯云 ASR 一致，免转码）
