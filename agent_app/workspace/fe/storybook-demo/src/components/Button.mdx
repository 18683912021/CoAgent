# Button 按钮

通用按钮组件。这里演示的是 **MDX 文档页**：你可以像写 Markdown 一样自由排版，

## 一、怎么用

```tsx

<Button>开始面试</Button>
<Button variant="secondary" icon={<Mic />}>开始录音</Button>
```
