# 轻松面试助手 — 产品计划

## 项目概述
AI 驱动的面试辅助 App。求职者面试时用手机麦克风录制对话，AI 实时转写并生成面试分析报告。

## 产品形态
- **仅手机 App**（iOS + Android），Expo React Native
- 单设备运行，无需多设备协同
- 麦克风采集为主，不依赖外部硬件

## 核心功能

### P0 — MVP
| 功能 | 说明 |
|------|------|
| 音频录制 | 手机麦克风采集，支持后台录制 |
| 语音转写 | 音频上传后端，ASR 引擎转文字 |
| 面试报告 | AI 分析对话内容，生成面试评估报告（语速/用词/逻辑/改进建议） |

### P1 — 二期
| 功能 | 说明 |
|------|------|
| 实时提示 | 面试中震动/弹窗提醒（如"语速过快"） |
| 历史记录 | 面试记录列表 + 报告回看 |
| 面试准备 | 输入 JD，AI 生成模拟问题 |

### P2 — 可砍
| 功能 | 说明 |
|------|------|
| 多语言 | 英文面试支持 |
| 视频录制 | 摄像头采集表情/肢体语言 |

## 阶段规划

| 阶段 | 内容 | 预估 |
|------|------|------|
| 0.1 | 项目脚手架搭建 | FE+BE |
| 0.2 | 音频录制模块（FE）+ 文件上传 API（BE） | FE+BE |
| 0.3 | ASR 转写服务对接 | BE |
| 1.0 | 面试报告生成 + 报告页 UI | FE+BE |
| 1.1 | 历史记录 | FE+BE |
| 2.0 | 实时提示（P1） | FE+BE |

## 技术边界
- FE：Expo + React Native，使用 expo-av 做音频采集
- BE：待 @酱瓜 确认技术栈（建议 Node.js/Express 或 Python/FastAPI）
- 通信：RESTful API，音频文件通过 multipart 上传
- ASR：优先对接第三方云服务（如阿里云/讯飞/Azure）
