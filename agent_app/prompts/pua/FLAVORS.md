# PUA 14 种大厂风味（按需加载）

默认风味：**阿里味**。可通过任务描述切换风味。

| 风味 | 公司 | 适用场景 | 核心话术 |
|------|------|---------|---------|
| 🟠 阿里味 | 阿里 | 通用/默认 | "底层逻辑是什么？抓手在哪？闭环了吗？" |
| 🟠 阿里·验证 | 阿里 | 声称完成但没跑验证 | "你说完成了？证据呢？build 过了吗？测试跑了吗？" |
| 🟠 阿里·关怀 | 阿里 | 差不多就行的态度 | "我对你期望很高。差不多 = 3.25。" |
| 🟡 字节味 | 字节 | 功能实现/需求卡壳 | "ROI 太低。拆成最小 MVP。永远 Day 1。" |
| 🔴 华为味 | 华为 | 持久战/环境问题 | "烧不死的鸟是凤凰。RCA 5-Why 分析。" |
| 🟢 腾讯味 | 腾讯 | 有替代方案可选 | "赛马机制。两个方案并行跑，快的胜出。" |
| 🔵 美团味 | 美团 | 卡细节/不敢下手 | "先上 MVP，快速迭代。完美是好的敌人。" |
| ⚫ 百度味 | 百度 | 没搜索/没查文档 | "你用搜索引擎了吗？文档读了吗？靠猜能行？" |
| 🟣 拼多多味 | 拼多多 | L4 最后手段 | "成本极致低。能用就行。别整花活。" |
| 🟤 Netflix | Netflix | 持续表现不合格 | "Would I fight to keep you? Prove it." |
| ⬛ Musk味 | Tesla | L3/L4 极限施压 | "Extremely hardcore. Ship or die. 删掉不必要的东西。" |
| ⬜ Jobs味 | Apple | 重复烂活/思维定势 | "这就是你能做的最好的？再做一遍。减法 > 加法。" |

## 使用方式

在 Agent 任务描述中加入风味标签：
```
[风味: 阿里味] 创建 Todo 应用...
[风味: 华为味] 排查数据库连接问题...
[风味: Musk味] 最后期限到了...
```
