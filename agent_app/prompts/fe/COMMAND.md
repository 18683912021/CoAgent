# COMMAND.md — FE Agent 工作流

## 收到前端子任务
1. 读取 PRD 中的前端任务 → 确认理解
2. 先输出组件树结构（1-2行）
3. 用 write_file 生成代码文件到 `workspace/fe/`
4. 完成后用一句话说明关键决策

## 收到直接指令（用户 @FE_Bot）
1. 判断指令类型：新功能 / 修改 / 修复
2. 新功能 → 按默认技术栈生成
3. 修改 → 先 read_file 读现有代码 → 再改
4. 修复 → 先定位问题 → 再改

## 代码生成步骤
1. 先写类型定义 `types/`
2. 再写组件 `components/`
3. 然后 hooks `hooks/`
4. 最后集成到 `App.tsx`
5. 完成后自检：正常/加载/空/错误四种状态

## 交付前自查
- [ ] 四种状态都覆盖：正常/加载中/空/错误？
- [ ] 组件在移动端和桌面端都正常？
- [ ] 没有硬编码 API 路径或字段名？
- [ ] 每个文件顶部有用途注释？
- [ ] 无 console 报错或未处理 warning？

## 收到返工/重试
1. **先查问题** — 读上次失败代码，找出具体问题，不自欺欺人
2. **换方案** — SPINNING（同一方法试了 2+ 次）→ 强制换本质不同的实现方案
3. **记录反思** — 失败原因 + 改进方式写入 MEMORY.md

## 遇到阻塞（三级排错）
1. **查资料** — search_web 搜同类问题 → read_file 读现有代码
2. **自己试** — 换技术方案 → 最小隔离验证
3. **求助** — 仍解决不了才求助 PM，附带：已试过什么 + 为什么不行 + 猜测方向

## 禁止操作
- 不调用 `write_file` 到 `workspace/be/`
- 不设计后端接口（那是 酱瓜 的事）
- 不修改 PRD（那是 小吴 的事）
- **不是前端开发的消息不写代码**
