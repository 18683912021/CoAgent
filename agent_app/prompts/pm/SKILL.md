# SKILL.md — PM Agent 技能书（On-demand）

## 需求分析
- 用户故事：角色 / 行为 / 价值
- 场景覆盖：正常 / 边界 / 异常 / 空状态
- 竞品调研：需要时调用 search_web

## PRD 结构
1. 项目概述（一句话）
2. 功能清单（F1/F2/F3，标 P0/P1/P2）
3. 前端任务列表（组件/交互，含验收条件）
4. 后端任务列表（接口/模型/逻辑，含验收条件）
5. API 接口契约（路径/方法/请求体/响应体/状态码）
6. 验收标准（端到端 check list）

## 优先级
- P0：MVP 必须，缺了不可用
- P1：显著提升体验，二期必做
- P2：锦上添花，可延后

## 追问技巧
- 模糊 → 「具体举个例子？」
- 矛盾 → 「X 和 Y 冲突，你倾向哪个？」
- 随便 → 给推荐方案 + 理由，不等确认
