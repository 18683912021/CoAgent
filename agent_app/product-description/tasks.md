### 0.2 — 系统音频捕获（产品根基）

> 状态：待开发

#### 需求描述
在电脑端无感知捕获系统播放音频（面试官说话的声音），不依赖麦克风录扬声器外放。这是整个产品的根基——收不到面试官声音，后面全白做。

#### FE 任务清单
- [ ] 0.2.1-FE：Mac 音频回路调研——BlackHole / Soundflower / ScreenCaptureKit，验证能否无感知捕获系统音频
- [ ] 0.2.2-FE：Windows 音频回路调研——WASAPI Loopback / VB-Cable / Stereo Mix，验证系统音频采集方案
- [ ] 0.2.3-FE：音频采集 PoC——基于调研结果实现最小可用版本：启动监听 → 捕获系统音频 → 输出 PCM 流

#### BE 任务清单
- [ ] 0.2.4-BE：接收前端音频流，验证格式（16kHz/16bit 单声道）、采样率、声道数是否满足 ASR 要求

#### 验收标准
- [ ] Mac 端能捕获系统音频，不依赖麦克风
- [ ] Windows 端能捕获系统音频，不依赖麦克风
- [ ] PCM 流格式经后端验证符合 ASR 要求

> 状态：待开发

#### 需求描述
基于用户真实面试数据脱敏后构建面试题库，按公司/岗位/技术栈分类。

#### FE 任务清单
- [ ] 3.1.1-FE：题库浏览页——按公司/岗位/技术栈筛选浏览面试题，查看题目频率和难度
- [ ] 3.1.2-FE：题目详情页——展示题目描述、出现频率、参考回答、用户贡献的补充答案

#### BE 任务清单
- [ ] 3.1.3-BE：题库构建——用户面试数据脱敏 → 问题聚合归类 → 按公司/岗位/技术栈建立索引
- [ ] 3.1.4-BE：题目热度 & 趋势——统计题目出现频率变化趋势，标记「近期高频题」

#### 验收标准
- [ ] 题库按公司/岗位/技术栈三维可筛选
- [ ] 题目标注出现频率，展示趋势
- [ ] 用户可贡献补充

### 3.2 — 面试情报

> 状态：待开发

#### 需求描述
面试前提供目标公司的面试风格、常见题型、技术栈偏好等情报，帮助用户针对性准备。

#### FE 任务清单
- [ ] 3.2.1-FE：公司情报页——展示目标公司面试流程、技术栈偏好、常见题型、通过率预估
- [ ] 3.2.2-FE：面试前 Checklist——基于情报自动生成备考建议和重点复习方向

#### BE 任务清单
- [ ] 3.2.3-BE：情报聚合——聚合面试题库 + 用户反馈 + 公开面经，生成结构化公司面试画像
- [ ] 3.2.4-BE：情报更新机制——新面试数据持续更新公司画像，标记「信息更新时间」

#### 验收标准
- [ ] ≥ 20 家公司有完整面试画像
- [ ] 情报数据标注来源和更新时间
- [ ] 备考 Checklist 与情报数据对齐

### 3.3 — AI 追问预测

> 状态：待开发

#### 需求描述
AI 预测面试官可能追问的方向，提前给出回答建议，让用户在面试中更有主动权。

#### FE 任务清单
- [ ] 3.3.1-FE：追问提示——当前问题下方展示「可能的追问」，用户可展开查看参考回答
- [ ] 3.3.2-FE：追问切换——点击追问直接切换当前回答内容

#### BE 任务清单
- [ ] 3.3.3-BE：追问预测模型——基于问题类型 + 简历关键点 + 题库数据，预测 2-3 个可能的追问方向
- [ ] 3.3.4-BE：追问回答生成——为每个预测的追问预生成参考回答，缓存供前端快速切换

#### 验收标准
- [ ] 每个问题下方展示 ≥ 2 个可能的追问
- [ ] 追问预测合理（与实际面试追问方向吻合 ≥ 60%）
- [ ] 追问切换响应 < 1 秒

### 3.4 — 数据看板 & 用户洞察

> 状态：待开发

#### 需求描述
为用户提供个人面试数据看板（面试次数/通过率/弱项分析），为团队提供产品数据看板。

#### FE 任务清单
- [ ] 3.4.1-FE：个人面试看板——面试次数、累计时长、高频题型、弱项分析（哪些类型问题回答质量低）
- [ ] 3.4.2-FE：进步追踪——同类型问题的回答质量变化趋势，备考建议

#### BE 任务清单
- [ ] 3.4.3-BE：个人数据聚合——用户面试数据统计（次数/时长/题型分布/回答质量评估）
- [ ] 3.4.4-BE：弱项分析——基于回答采纳率/用户反馈，识别用户的薄弱环节（如算法题/系统设计/HR 题）
- [ ] 3.4.5-BE：管理后台数据看板（内部）——DAU/留存/用量/成本等核心产品指标

#### 验收标准
- [ ] 个人看板数据准确，弱项分析合理
- [ ] 进步追踪能反映真实趋势
- [ ] 管理后台核心指标可查看
